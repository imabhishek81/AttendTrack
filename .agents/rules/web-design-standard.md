# Universal Web Design & Aesthetics Standard

When creating, updating, or styling any web application or component in this repository:

## Mandatory Skills & Principles
You must strictly adhere to and execute the following 5 design disciplines:
1. **Anthropic Frontend Design**: Clean editorial typography, purposeful spacing, high clarity, and thoughtful user-centered flows.
2. **UI/UX Pro Max**: Dynamic micro-animations, glassmorphism, fluid spring curves (`cubic-bezier(0.16, 1, 0.3, 1)`), ambient lighting accents, and zero-latency optimistic state updates.
3. **Vercel Web Design Guidelines**: Obsidian dark themes (`#08090E`), 1px specular borders (`border-white/[0.08]`), pill badges, live pulsing radar status indicators, and sleek typography.
4. **Vercel Composition Patterns**: Decoupled compound component hierarchies, polymorphic primitives, pure presentation separation, and clean slot architectures.
5. **Impeccable Craft**: Zero sloppy layout shifts, optical alignment, delightful empty states, responsive touch/click states (`active:scale-95`), and rich micro-copy.

## Anti-Dull Constraint
- **NEVER** build floppy, dull, generic, or boring web interfaces.
- **NEVER** use plain browser default inputs, unstyled buttons, or raw unpadded tables.
- **ALWAYS** deliver visually stunning, state-of-the-art web applications that delight the user at first glance.
