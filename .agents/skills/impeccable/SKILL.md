# Impeccable Craft Standard

Never tolerate sloppy, dull, uninspired, or generic web interfaces. Every pixel, interaction, and state must reflect craftsmanship.

## Rules of Impeccable Quality

1. **Anti-Dull Principle**:
   - Never build plain HTML forms with default gray inputs and raw buttons.
   - Every interface must feel dynamic, responsive, and alive with refined aesthetics, smooth glows, and tactile visual feedback.

2. **Zero Layout Shifts**:
   - Reserve space for loading indicators, avatars, and numbers to prevent jarring jumpiness.
   - Use skeleton pulse loaders matching the exact dimensions of final content.

3. **Pixel-Perfect Alignment & Spacing**:
   - Follow strict 4px/8px modular rhythm (`gap-2`, `gap-3`, `gap-4`, `p-4`, `p-6`).
   - Align icons optically with labels (`flex items-center gap-2`).

4. **Flawless Contrast & Hierarchy**:
   - High contrast headers (`text-white`, `font-bold`, `tracking-tight`).
   - Distinct secondary metadata (`text-surface-400`, `font-medium`, `text-xs`).
   - Accessible color ratios for all text on dark or colored backgrounds.

5. **Instant Feedback & Tactile Delight**:
   - Provide micro-feedback for every user tap: ripple, slight scale down on click, toast confirmation on save, subtle sound/haptic cues where applicable.
