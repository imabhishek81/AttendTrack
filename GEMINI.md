# Workspace Configuration & Design Directives

## Web Creation Standards
Every web application or UI feature created in this workspace MUST strictly follow:
- **anthropic-frontend-design**
- **ui-ux-pro-max**
- **vercel-web-design-guidelines**
- **vercel-composition-pattern**
- **impeccable**

Never build dull, flat, or floppy interfaces. Ensure every page has obsidian styling, specular borders, spring animations, and top-tier polish.
