# Agent Instructions & Design Directives

## Mandatory Web Design Stack & Skills
Whenever designing, building, or modifying any frontend or web interface in this project:
1. **anthropic-frontend-design**: Editorial hierarchy, clarity over clutter, thoughtful interactive states.
2. **ui-ux-pro-max**: Modern glassmorphism, fluid spring animations, ambient glow highlights, zero-latency optimistic UI.
3. **vercel-web-design-guidelines**: Obsidian dark theme (`#08090E`), 1px specular borders, pulsing radar status pills.
4. **vercel-composition-pattern**: Compound component structure, clean decoupling, composable slots.
5. **impeccable**: Pixel-perfect alignment, zero layout shift, rich micro-interactions, delightful empty states.

## Core Rule: Anti-Dull & High-End Craft
- **Do not create floppy, dull, generic, or boring UI.**
- Always apply curated color harmony, obsidian backgrounds, smooth gradients, dynamic hover responses, and polished typography.
